# أورادنا

ورد اليوم من كتاب «أورادنا» (الطريقة الصديقية الشاذلية) في جلسات قصيرة بعد كل صلاة.

- `mobile/` — the iPhone and Android app (Expo / React Native): native reader, prayer-time reminders, home-screen widgets.
- `site/` — the web version (static), deployed at awradna.netlify.app.
- `CLAUDE.md` — how the app works: the content map, the reading plan, and the rules.
